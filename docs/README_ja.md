## Phase 1 ドキュメント

Phase 1で実装された機能のドキュメントを以下に示します。

### 基本機能

#### マトリックススキャン
- COL2ROW / ROW2COL 両対応
- 3ms デバウンス（設定可能）
- 1ms スキャン間隔（1000Hz）
- 最大 16x8 マトリックス（片側）

#### キーコード体系
- 基本キー: USB HID準拠（0x00-0xFF）
- モディファイア: 8種類（Ctrl, Shift, Alt, GUI x 左右）
- レイヤー操作: MO, TG, TT, LT
- ゲームパッドボタン: 32個（GP_BTN1-32）

#### レイヤーシステム
- 最大16層
- ビットマップベースの高速レイヤー切り替え
- 透過キー（KC_TRNS）対応
- モーメンタリ、トグル、タップトグル、レイヤータップ

### 周辺機器

#### ジョイスティック
- 12bit ADC入力
- オーバーサンプリング（4サンプル平均）
- 起動時自動キャリブレーション
- デッドゾーン処理（±5%）
- 軸反転機能

#### OLED
- SSD1306ドライバ（I2C）
- 128x32 および 128x64 対応
- レイヤー番号表示
- ジョイスティック値表示
- CapsLock/NumLock状態表示

### 分割キーボード

#### 通信プロトコル
- UART 460800bps
- マトリックス状態転送
- ジョイスティック値転送
- チェックサム検証
- 5ms タイムアウト

#### 対応構成
- マスター/スレーブ構成
- 片側最大16x8マトリックス
- 両側ジョイスティック対応（2軸分）
- マスター側のみOLED（Phase 1）

## Phase 2〜4 実装済み機能

### Phase 2: 拡張機能
- ロータリーエンコーダー（最大2個、クリック対応）
- RGB LED（WS2812、最大128個、基本エフェクト3種）
- 分割キーボード双方向通信（LED/OLED同期）
- OLED両側表示
- タップ検出（TT/LT）
- ジョイスティック詳細キャリブレーション

### Phase 3: 高度な機能
- リアクティブLEDエフェクト（KeyPress、FadeOut、Ripple）
- エフェクトレジストリ（最大16エフェクト）
- 分割キーボード両側LED制御（Unified/Independentモード）
- パフォーマンス最適化（ヒープ割り当て95%削減）
- デバッグモード（DebugLogger）
- エラー処理改善（Stats構造体）

### Phase 4: VIA/Remap対応
- NKRO対応（6KRO/NKRO動的切り替え）
- マクロ機能（最大16マクロ、各最大32ステップ）
- コンボキー（最大16コンボ、2〜4キー同時押し）
- 設定の永続化（Flashベース保存）

詳細は [ROADMAP.md](../ROADMAP.md) を参照してください。
